# Food Supplier Finder

Простой Streamlit-сервис для менеджера по закупкам: поиск поставщиков продуктов по смысловому запросу, фильтры по категории и городу, автоматический рейтинг, сортировка и сравнение.

## Что реализовано

- семантический поиск по естественному языку;
- фильтры по категории и городу;
- результаты появляются сразу после выбора категории или города, даже без текстового запроса;
- автоматический рейтинг поставщика по шкале 1–5;
- сортировка по рейтингу (возрастание/убывание), минимальному объёму заказа, цене и количеству выполненных заказов;
- лучший вариант автоматически определяется после применения запроса и фильтров и визуально подсвечивается;
- карточка поставщика с минимальным заказом, ценой, количеством выполненных заказов, документами, доставкой, регионом, контактами, сайтом и заметками;
- выбор поставщиков и встроенное сравнение;
- итоговое решение пользователю показывается без раскрытия внутренней формулы рейтинга;
- fallback на TF-IDF, если embedding-модель недоступна в окружении.

## Как устроено

1. `data/suppliers.csv` — демонстрационный датасет, включая историю количества заказов.
2. `src/data.py` — загрузка и подготовка данных.
3. `src/search.py` — embeddings, поиск, внутренний scoring, рейтинг и сравнение.
4. `app.py` — Streamlit UI, фильтры и сортировка.
5. `tests/` — базовые проверки данных и логики.

Основной режим использует `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, чтобы запросы на русском сопоставлялись с описаниями товаров по смыслу, а не только по совпадению слов.

### Внутренний ranking

При наличии текстового запроса сервис учитывает соответствие запросу, коммерческие условия, логистику и полноту карточки. При использовании только фильтров работает отдельный ranking без семантического запроса — по коммерческим и операционным сигналам и полноте данных.

Веса являются частью внутренней логики сервиса и пользователю не показываются.

### Рейтинг 1–5

Пользователь видит простой рейтинг `1.0–5.0`, рассчитанный из внутреннего итогового score. Этот рейтинг используется также для сортировки результатов.

## Локальный запуск

```bash
python -m venv .venv

# Windows
.venv\\Scripts\\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение доступно на `http://localhost:8501`.

## Деплой в Streamlit Community Cloud

1. Создать GitHub repository.
2. Загрузить весь проект.
3. В Streamlit Cloud выбрать `app.py` как entry point.
4. Deploy.

При первом запуске embedding-модель будет скачана и закеширована через `st.cache_resource`.

## Production

Демонстрационный CSV нужно заменить на реальный источник поставщиков (БД/API/файл). UI и ranking-слой при этом можно сохранить практически без изменений.
