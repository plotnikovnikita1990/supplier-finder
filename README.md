# 🛒 AI Supplier Intelligence

AI-прототип для поиска, сравнения и предварительного выбора поставщиков продуктов питания.

Проект выполнен как решение второй части тестового задания: пользователь задаёт потребность в естественной форме, сервис находит поставщиков по смыслу, учитывает регион и бизнес-ограничения, ранжирует кандидатов, показывает причины рекомендаций и позволяет подготовить запрос поставщику.

> **Важно:** demo dataset синтетический. Он нужен для демонстрации продукта и алгоритма. Перед коммерческим использованием данные должны быть заменены на проверенные источники.

## Что умеет

- поиск по категории товара;
- поиск по городу/региону;
- semantic search на русскоязычной embedding-модели;
- структурирование естественного запроса;
- hard filters для обязательных условий;
- hybrid ranking;
- настраиваемые веса критериев;
- объяснение итогового score;
- сравнение до 4 поставщиков;
- контакты и источник данных;
- генерация RFQ/запроса коммерческого предложения;
- unit tests и CI.

## Запуск

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

При первом запуске Sentence Transformers скачает embedding-модель.

## Docker

```bash
cp .env.example .env
docker compose up --build
```

Открыть `http://localhost:8501`.

## UX

Интерфейс сознательно построен как B2B-каталог: крупный поиск сверху, быстрые сценарии, фильтры, карточки поставщиков, score, сравнение и следующий шаг — запрос коммерческого предложения.

По визуальной логике он ориентирован на понятные B2B-маркетплейсы: каталог, карточки, цены, условия, фильтрацию и сравнение, но не копирует дизайн или контент стороннего сервиса.

## Почему hybrid search

Keyword-only поиск плохо работает с запросами вроде «молочка» или «упаковка для кафе». Embeddings позволяют учитывать смысл. Но semantic similarity недостаточно для закупки, поэтому после retrieval применяются бизнес-признаки и hard constraints.

## Что означают оценки

`Match 0–100` — это ranking score, а **не вероятность**, не рейтинг поставщика и не гарантия качества.

Цена, MOQ и другие признаки нормализуются относительно текущего набора кандидатов.

## Production roadmap

3. Ingestion прайс-листов/API.
4. LLM query parser с structured output.
5. Labeled evaluation set, Recall@K и NDCG@K.
6. Мониторинг freshness источников.
7. FastAPI backend + отдельный frontend.
8. Авторизация, аудит и история поиска.
