# Food Supplier Finder

Простой прототип сервиса для менеджера по закупкам: поиск поставщиков продуктов по смысловому запросу, фильтры по категории и городу, карточки с ключевой информацией и автоматическое сравнение.

## Что реализовано

- семантический поиск по естественному языку;
- фильтры по категории и городу;
- ранжирование поставщиков без ручной настройки весов;
- карточка поставщика: минимальный заказ, ориентир цены, документы, доставка, регион работы, контакты, сайт и заметки;
- выбор поставщиков и встроенное сравнение;
- выдача итогового решения пользователю без показа внутренней формулы рейтинга;
- fallback на TF-IDF, если embedding-модель недоступна в окружении.

## Как устроено

1. `data/suppliers.csv` — демонстрационный датасет.
2. `src/data.py` — загрузка и подготовка данных.
3. `src/search.py` — embeddings, поиск, внутренний scoring и сравнение.
4. `app.py` — Streamlit UI.
5. `tests/` — базовые проверки данных и логики сравнения.

Для основного режима используется `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, чтобы запросы на русском сопоставлялись с описаниями товаров по смыслу, а не только по совпадению слов.

Внутренний ranking использует четыре группы сигналов:

- 60% — соответствие запросу;
- 20% — коммерческие условия;
- 12% — операционная/логистическая пригодность;
- 8% — полнота данных поставщика.

Эти веса являются частью логики сервиса и пользователю не показываются.

## Локальный запуск

```bash
python -m venv .venv

# Windows
.venv\\Scripts\\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение доступно на `http://localhost:8501`.

## Деплой в Streamlit Community Cloud

1. Создать GitHub repository.
2. Загрузить весь проект.
3. В Streamlit Cloud выбрать `app.py` как entry point.
4. Указать Python 3.11+.
5. Deploy.

При первом запуске embedding-модель будет скачана и закеширована через `st.cache_resource`.

## Что заменить для production

Демонстрационный CSV нужно заменить на реальный источник поставщиков (БД/API/файл). UI и ranking-слой при этом менять минимально.
